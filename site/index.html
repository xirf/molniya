Start with one file

Keep the steps close.

Set the input types, choose the rows, group them, then ask for the result. This API is experimental and does not match earlier Molniya releases.

Read the current guide ↗ 
import { readCsv, col, lit, gt, sum } from "molniya";

const rows = await readCsv("sales.csv", {
  region: "utf8", amount: "f64",
})
  .where(gt(col("amount"), lit(10)))
  .aggregate(["region"], {
    total: sum(col("amount")),
  })
  .collect();
